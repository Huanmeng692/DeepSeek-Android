# DeepSeek Android v1.0.2

第三方 DeepSeek Android 客户端。不是 DeepSeek 官方客户端，与深度求索公司无隶属关系。

## 新增：官方历史对话导入/导出

设置 → 数据：

- **导入对话历史**：支持官方网页版/新版 App 导出的
  `deepseek_data-日期.zip`（`export_format_version: 3`）。
  - 合并导入，不删除本机其他对话；同 ID 会话会更新。
  - 按 `current_message_id` 还原官方当前分支。
  - 保留提问、回答、思考、搜索来源、打开网页、阅读链接、图片原件与文件元数据。
  - 缺失原件的附件显示为“仅记录”，不会参与后续上传。
- **导出全部对话**：生成同格式 `deepseek_data-日期.zip`，包含消息树和本地存在的图片原件。
  - 归档不包含 API Key、账号、登录信息或应用设置。
  - 兼容官方导出 schema，以及 chat-demo / DeepSeek Harness 的官方历史导入实现。
  - 官方 App/网页是否提供直接“导入”按钮取决于其当前版本；导出的格式与官方导出一致。

### 验证

使用真实官方导出样例做了往返测试：

```text
108 个会话 / 356 条消息 / 71 个附件 / 71 张图片
导入 → 导出 → 再次导入：108 个会话全部保留
```

同时验证了 Android 系统文件选择器导入、`CreateDocument` 导出与导出 ZIP 的
manifest/index/session 结构。

## 安装说明

- 最低 Android 7.0（API 24），targetSdk 37；
- 本版本使用与 1.0.1 相同的发布签名，可覆盖安装 1.0.1 Release；
- 如果手机上安装的是 Debug 版或旧签名 APK，需要先卸载（会清除本机聊天记录和加密凭据）；
- 发布证书 SHA-256：
  `FE:38:7B:28:3D:57:9C:C9:85:BF:0E:DB:E2:FB:16:61:60:48:95:CD:58:CC:E0:1B:48:6A:7C:BE:9B:FF:70:E1`
- 附件 APK 的 SHA-256：

```text
58E5D4AD5A14F5293830522FF37826BF7DC2F2FEC8FFAE7D9DDB948878E27E3C
```

## 已知限制

- 导入只保留官方当前分支；其他分支不进入本应用的线性会话。
- 非图片附件只有元数据；官方 ZIP 本身也不包含非图片原件。
- 未知/不需要展示的片段（TIP、CONTENT_RISK、TOOL_IMAGE_SEARCH、PARTIAL_FILE_READ 等）会丢弃。
- 平台账号接口属于前端非公开接口，平台改版后可能失效；可回退到手动 API Key。
