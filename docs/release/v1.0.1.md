# DeepSeek Android v1.0.1

第三方 DeepSeek Android 客户端。不是 DeepSeek 官方客户端，与深度求索公司无隶属关系。

## 更新内容

- 修复平台登录 WebView 中手机号/验证码输入时光标跳到开头、数字倒序的问题：
  - 关闭 WebView 自动填充；
  - 登录页注入 `tel` / 数字输入框光标恢复脚本；
  - 移除自定义 UA 后缀。
- 修复对话请求 `latest_reminder` 的平台字段：`Android` → `App`，解决
  `unknown platform 'Android'` 的 HTTP 400。
- 保留 1.0.0 的全部功能：流式对话、深度思考、联网搜索、来源卡片、Markdown、
  附件、语音/TTS、多会话、主题与中英文、账号托管 API Key、余额、充值与用量。

## 安装说明

- 最低 Android 7.0（API 24），targetSdk 37；
- 本 Release 使用新的发布签名证书：
  `FE:38:7B:28:3D:57:9C:C9:85:BF:0E:DB:E2:FB:16:61:60:48:95:CD:58:CC:E0:1B:48:6A:7C:BE:9B:FF:70:E1`
- **如果手机上安装的是 Debug 版或旧签名的 APK，需要先卸载再安装本 Release**
  （签名不同无法覆盖；卸载会清除本机聊天记录和加密凭据）。安装后重新登录账号即可重新创建 Key。
- 附件 APK 的 SHA-256：

```text
BDCB32E67CFA03A3C054AF1A57457DCA1ADF921F47D13B40C7F20DB1CD62E97F
```

## 账号与隐私

- 登录后自动创建专用 API Key（名称 `DeepSeek Android`）并保存在 Android Keystore 加密存储；
- 平台账号接口属于前端非公开接口，平台改版后可能失效；可回退到手动 API Key；
- 对话直接发送到 `api.deepseek.com`，无自建服务器与遥测。

## 已知限制

- 平台截图中的 “App-managed” 是 DeepSeek Harness 专用 Key 类型；本应用创建的是普通专用 Key，
  应用内标识为“应用托管”。
- 未实现消息分支、历史 ZIP 导入导出、Mermaid 和完整 KaTeX。
